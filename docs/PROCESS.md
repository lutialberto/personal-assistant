# Procesos del proyecto

## Cómo se toma una decisión

1. Se discute en el chat.
2. Se define.
3. Se documenta en el archivo correspondiente.

Las decisiones no quedan solo en el historial del chat — si no están escritas, no existen.

## Cómo se documenta algo nuevo

| Tipo | Archivo |
|---|---|
| Convenciones (idiomas, commits, estructura) | `CONVENTIONS.md` |
| Procesos de trabajo | `PROCESS.md` |
| Etapas, entregables, criterios de cierre | `STAGES.md` |
| Estado vivo del trabajo | `STATE.md` |
| Tareas pendientes | `TODO.md` |

## Cómo se avanza de etapa

1. Verificar que todos los entregables de la etapa actual están cumplidos (ver `STAGES.md`).
2. Actualizar `STATE.md` con la nueva etapa.
3. Actualizar el estado en `STAGES.md`.

## Cómo se maneja algo fuera de scope

Si surge algo que corresponde a una etapa futura, se anota en `TODO.md` con la etapa que corresponde. No se resuelve en el momento.
